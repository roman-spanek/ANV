Níže je ukázka produkčního kódu, který porušuje základní principy čistého kódu.
   Vaším úkolem je:
   Identifikovat problémy v návrhu
   Navrhnout refaktorované řešení
   Použít vhodné návrhové vzory
   Vysvětlit proč byly vzory použity

class OrderManager {

    public void processOrder(int type, double amount, boolean vip, String output) {

        double finalAmount = amount;

        if (vip) {
            finalAmount = amount * 0.9;
        }

        if (type == 1) {
            System.out.println("Processing online order");
            if (output.equals("PDF")) {
                System.out.println("Generating PDF invoice");
            } else if (output.equals("EMAIL")) {
                System.out.println("Sending invoice by email");
            }
        } else if (type == 2) {
            System.out.println("Processing store order");
            System.out.println("Printing invoice");
        }

        System.out.println("Final price: " + finalAmount);
    }
}

ukázku refaktorovaného kódu (kostra tříd)
seznam problémů
seznam použitých vzorů
