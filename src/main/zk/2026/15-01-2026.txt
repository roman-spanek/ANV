Níže je ukázka produkčního kódu, který porušuje základní principy čistého kódu.
   Vaším úkolem je:
   Identifikovat problémy v návrhu
   Navrhnout refaktorované řešení
   Použít vhodné návrhové vzory
   Vysvětlit proč byly vzory použity

public class ReportService {

    public void generateReport(String type, String format, boolean admin, boolean archive) {
        if (admin) {
            System.out.println("Including confidential data");
            if (type.equals("FINANCE")) {
                System.out.println("Collecting finance data");
            } else if (type.equals("HR")) {
                System.out.println("Collecting HR data");
            } else {
                System.out.println("Unknown report type");
                return;
            }
        }else{
            if (type.equals("FINANCE")) {
                System.out.println("Collecting finance data");
            } else if (type.equals("HR")) {
                System.out.println("Collecting HR data");
            } else {
                System.out.println("Unknown report type");
                return;
            }
        }

        if (format.equals("PDF")) {
            System.out.println("Exporting report as PDF");
        } else if (format.equals("CSV")) {
            System.out.println("Exporting report as CSV");
        } else if (format.equals("XML")) {
            System.out.println("Exporting report as XML");
        }

        if (archive) {
            System.out.println("Saving report to archive");
        }
    }
}

seznam problémů
seznam použitých vzorů
použijte vhodné návrhové vzory (bez použití Strategy a Decorator)

--------------------------------------------------------------------------------------------

Navrhněte základní architekturu softwaru pro systém správy přístupových práv ve firemní aplikaci.
Systém musí:
    podporovat různé typy uživatelů (např. Admin, Manager, Employee)

POŽADAVKY NA NÁVRH:

        otevřený rozšíření
        uzavřený změnám
    preferujte kompozici před dědičností
